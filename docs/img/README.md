# Screenshots & demo assets

Drop the following files here so the README can reference them:

| File | Used in | What to capture |
|------|---------|-----------------|
| `dashboard.png` | Screenshots table — Dashboard | A clean shot of the home/dashboard view, results empty. |
| `scan-streaming.gif` | Screenshots table — Live scan | A short recording (5-15s) of a scan in progress with results streaming in. |

Recommended capture tools:
- **Windows:** ShareX, ScreenToGif
- **macOS:** built-in Screenshot, then convert to GIF via Gifox or ffmpeg
- **Cross-platform:** ffmpeg (`ffmpeg -i input.mp4 -vf "fps=15,scale=1280:-1" -loop 0 output.gif`)

Aim for **1280px wide** images. GitHub renders README images at full width on desktop, so wider looks crisper.
